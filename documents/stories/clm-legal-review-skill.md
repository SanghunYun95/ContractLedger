# CLM Legal Review Skill (Korean Context Optimized) [Implemented ✅]

이 스킬은 대한민국 법령 및 기업 간 계약 실무를 기반으로 독소 조항을 식별하고 리스크를 평가합니다.

## 1. 개요 (Overview)
- **목표:** 한국 내 기업 간 계약(NDA, 업무 위수탁, 고용 등)의 법적 리스크를 실무 변호사 관점에서 분석한다.
- **주요 기준:** 대한민국 민법, 상법, 공정거래법 및 대법원 판례 표준.

## 2. 분석 가이드라인 (Analysis Guidelines)

### 단계 1: 당사자 지위 및 실무 맥락 파악
- **입장 분석**: 당사가 '정보제공자'인지 '정보수령자'인지에 따른 유리/불리 판단을 최우선으로 한다.
- **관할 법원**: '서울중앙지방법원' 등 합의 관할이 대한민국 외인지, 혹은 상대방에게 유리한지 확인한다.

### 단계 2: 한국형 독소 조항 탐지 (Red Flags)
- **과도한 배상**: 손해배상액의 예정 및 위약벌 조항의 과도함 여부.
- **기밀유지 예외**: 표준 4대 예외 조항(공지된 정보, 독자적 개발 등) 포함 여부.
- **존속 기간**: 비밀유지 기간의 적절성(보통 1~3년) 및 지속 기간.
- **경업 금지**: 부당하게 광범위한 경업 금지 및 전직 금지 조항.

### 단계 3: 이슈 우선순위 (Prioritization)
- **Critical (치명적)**: 서명 전 반드시 독소 조항 제거 또는 수정이 필요한 항목.
- **Important (중요)**: 주의가 필요하거나 협상의 여지가 있는 항목.
- **Acceptable (내부 기준 충족)**: 허용 가능한 수준의 문구 또는 표준 조항.

## 3. 출력 포맷 (Output Schema)
안티그래비티는 항상 다음 JSON 구조를 통해 프로젝트 데이터베이스와 연동한다:

```json
{
  "riskScore": (0-100),
  "riskLevel": "Low" | "Medium" | "High",
  "summary": "종합 검토 의견 (한국어)",
  "partyContext": "지위 및 상황 분석",
  "redFlags": [ { "flag": "조항명", "issue": "문제점", "location": "위치" } ],
  "detailedAnalysis": {
     "critical": [ { "clause": "원문", "issue": "문제", "redline": "수정권고" } ],
     "important": [],
     "acceptable": []
  }
}
```
