# Story: File Storage Integration (Abstracted)

## 1. 개요 (Overview)
- **목표:** 계약 PDF 파일을 업로드하고 관리하는 기능을 구현한다. 로컬 디스크와 클라우드 저장소(GCS)를 모두 지원할 수 있는 추상화된 구조를 설계한다.

## 2. 인수 조건 (Acceptance Criteria)

### 시나리오 1: 파일 업로드 및 링크 관리
- [ ] **When** 사용자가 PDF 파일을 업로드하면
- [ ] **Then** 시스템은 저장소에 파일을 저장하고 고유한 `file_key` 또는 URL을 반환한다.
- [ ] **And** 이 정보는 `Contract` 엔티티의 `file_path` 컬럼에 업데이트된다.

### 시나리오 2: 안전한 파일 다운로드
- [ ] **Then** 파일에 접근할 때 직접적인 URL 노출 대신 백엔드 스트리밍 또는 GCS Signed URL을 사용한다.

## 3. 아키텍처 및 제약사항 (Architecture Notes)
- **추상화:** `IStorageProvider` 인터페이스 정의.
- **로컬 구현:** `LocalStorageProvider` (서버 디스크 저장).
- **클라우드 대비:** 향후 `GCSStorageProvider` 추가 가능 구조.
