# Story: CLM Frontend Dashboard [Implemented ✅]

## 1. 개요 (Overview)
- **목표:** 백엔드 코어 모듈(Audit, Notification)과 연동되는 프론트엔드 대시보드를 Next.js 기반으로 구현한다. 플랫폼의 철학인 "The Architectural Vault" 프리미엄 디자인(DESIGN.md 참조)을 충실히 반영하여 멀티 테넌트 전환, 감사 로그 조회, 외부 웹훅 시뮬레이션 기능을 제공한다.

## 2. 페르소나 (Persona)
- **Tenant Administrator (테넌트 최고 관리자):** 자신이 소속된 테넌트의 모든 활동 기록(Audit Logs)을 확인하고 알림을 발생시키는 외부 AI의 상태를 모니터링한다.

## 3. 인수 조건 (Acceptance Criteria)

### 시나리오 1: 프리미엄 UI 디자인 시스템 적용 [Done ✅]
- [x] **Given** 사용자가 대시보드에 접속한다.
- [x] **When** 화면 렌더링 시
- [x] **Then** Tailwind CSS를 활용하여 `DESIGN.md` 및 `stich.html`에 명시된 다크 모드, 유리 질감(Glassmorphism), 그리고 Manrope/Inter 폰트 조합의 고품질 UI가 렌더링된다.

### 시나리오 2: 대상 테넌트 전환 (Tenant Switcher) [Done ✅]
- [x] **Given** 사용자가 상단 네비게이션(TopAppBar)의 테넌트 스위처를 클릭한다.
- [x] **When** 활성 테넌트(예: Acme Corp -> Globex)를 선택하여 변경하면
- [x] **Then** 선택된 테넌트 정보가 업데이트된다. (로컬 상태 관리 및 API 헤더 반영)

### 시나리오 3: 감사 로그(Audit Logs) 데이터 그리드 [Done ✅]
- [x] **Given** 사용자가 대시보드 메인 화면을 조회한다.
- [x] **When** 컴포넌트 마운트 시
- [x] **Then** 테넌트의 감사 로그 목록이 표(Table) 형태로 렌더링된다.
- [x] **And** 각 로그의 액션(Action) 타입에 따라 알맞은 색상의 뱃지(Badge)가 표시된다.

### 시나리오 4: 외부 AI 에이전트 웹훅 시뮬레이션 [Done ✅]
- [x] **Given** 사용자가 사이드바의 에이전트 시뮬레이터 구역에서 `Trigger AI Risk Alert` 버튼을 클릭한다.
- [x] **When** 클릭 이벤트가 발생하면
- [x] **Then** 웹훅 송신 효과를 트리거한다. (백엔드의 `POST /api/notifications/webhook` API 연동 완료)
- [x] **And** 화면에 성공 여부를 알리는 토스트(Toast) 메시지가 부드러운 애니메이션과 함께 나타난다.

## 4. 아키텍처 및 제약사항 노트 (Architecture Notes)
- **기술 스택:** Next.js (App Router), React, Tailwind CSS
- **API 통합:** 3000 -> 3001 Proxy(`next.config.ts`) 설정 완료. `x-tenant-id` 및 `Authorization` 헤더 주입 완료.
- **실시간성:** 5초 주기 폴링(Polling) 및 Webhook 트리거 시 즉시 새로고침(`refreshKey`) 연동 완료.
- **디자인 소스:** `frontend/design/stich.html`의 프리미엄 테마를 리액트 컴포넌트로 완벽 이식.
